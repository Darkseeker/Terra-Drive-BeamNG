## 📖 What is this?

**Terra-Drive-BeamNG** is a next-generation map mod that replaces the standard grid-based levels with a fully procedural, real-world replica of planet Earth. 

If you've ever wanted to drift down the streets of Tokyo, cruise the Pacific Coast Highway, or test off-road physics in the Andes, this is the tool for you. It pulls live terrain data from LiDAR, texture data from satellites, and road layouts from OpenStreetMap. 

Instead of keeping the entire 40-million-gigabyte world in your RAM, **Terra-Drive** uses a smart local server to stream chunks of the map in real-time as you drive. The game engine is tricked into thinking you are moving via a "Floating Origin" system, preventing floating-point precision errors during long-distance driving.
